Identitas Produk:Nama Aplikasi: MULATagline: "Mulai kecil. Tumbuh setiap hari."Platform: Android (Flutter — Offline-First Architecture).   Target Pengguna: Anggit.   Prinsip Utama: "Saya tidak harus sempurna. Saya hanya wajib kembali ke sistem pada blok berikutnya."   Tech Stack Wajib (Zero-Local-SDK & Zero-Codegen):Gunakan Flutter Material 3 dengan flutter_riverpod standar (TANPA riverpod_generator, TANPA freezed, dan TANPA build_runner agar kode langsung bisa di-compile di GitHub Actions tanpa langkah code generation).Gunakan sqflite dan path untuk database SQLite lokal, serta shared_preferences untuk preferensi sederhana.   Gunakan flutter_local_notifications, android_alarm_manager_plus, dan timezone untuk pengingat jadwal serta alarm presisi saat layar terkunci.   Gunakan local_auth untuk penguncian PIN/biometrik pada fitur sensitif.   Aturan Ketat Penulisan Kode (Zero-Placeholder Policy):DILARANG membuat tombol mati (onPressed: () {}), halaman dummy, atau komentar // TODO. Setiap tombol, input, dan gestur swipe wajib terhubung langsung ke fungsi sqflite dan mengubah state di flutter_riverpod.Semua perhitungan skor harian (total 100 poin) wajib terhitung secara otomatis dan reaktif dari penyelesaian tugas, jadwal, dan sesi fokus tanpa perlu dihitung manual oleh pengguna.   Timer wajib menggunakan perhitungan selisih timestamp (DateTime.now() terhadap startedAt) sebagai sumber kebenaran agar tetap berjalan akurat ketika layar HP mati atau terkunci.   Terapkan Circadian & Mood-Adaptive UI: warna latar belakang, aksen, sapaan, dan suasana layar berubah otomatis mengikuti jam biologis pengguna (Pagi 04.30–08.00, Kerja 08.00–16.00, Keluarga 16.00–20.00, Malam 20.00–22.00) serta berubah ke mode tenang (Sanctuary Mode) saat pengguna menekan tombol cemas, stuck, atau Mode Hari Buruk.
